# customer-behavior-analysis
📊 Data Analytics Project: End-to-End Analysis & Dashboard

📌 Overview
This project demonstrates an end-to-end data analytics workflow, covering data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, and business intelligence reporting. The goal is to extract meaningful insights from raw data and present them through an interactive Power BI dashboard and a concise report.
The project showcases practical skills in Python, SQL (PostgreSQL), and Power BI, along with clear data storytelling using reports and presentations.

▶️ How to Run This Project

Clone the repository:
git clone <repository-url>


Install required Python libraries:
pip install pandas numpy matplotlib seaborn


Open the Jupyter Notebook and run all cells to:
Load and clean the data
Perform EDA
Load the cleaned dataset into PostgreSQL.
Execute the provided SQL queries.
Open the Power BI file (.pbix) to explore the dashboard.

Review the report and presentation for final insights.
